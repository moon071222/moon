Connect Live Multi-User Backend (Firebase)

How to make this live for all students in 3 minutes (100% Free):

  1. Go to console.firebase.google.com and create a free project.
  2. Enable Authentication → Sign-in method → Email/Password.
  3. Enable Firestore Database → Create database (start in Production Mode).
  4. (Optional) Enable Storage if you want direct PDF uploads, or just paste Google Drive links for free.
  5. In Project Settings (Gear Icon) → Register a Web App (</>) and paste the firebaseConfig object below!

Note: Only the configured CR Admin email can receive administrator privileges.
